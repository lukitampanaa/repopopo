Definisi Logaritma

Konsep dasar logaritma

Logaritma adalah operasi kebalikan dari perpangkatan (eksponen). Jika ab = c, maka:

alog c = b   ⟺   ab = c

Dimana: a = basis (a > 0, a ≠ 1), c = numerus (c > 0), b = hasil logaritma.

Contoh: ²log 8 = 3, karena 2³ = 8

🔢

Logaritma Umum & Natural

log dan ln

Logaritma Umum (Basis 10)
log x = 10log x
Logaritma Natural (Basis e ≈ 2.718)
ln x = elog x

Info: log tanpa basis berarti basis 10. ln berarti basis e (bilangan Euler).

1️⃣

Sifat 1: Logaritma dari 1

alog 1 = 0

alog 1 = 0   (untuk semua a > 0, a ≠ 1)

Karena bilangan apapun dipangkatkan 0 hasilnya 1: a⁰ = 1

Contoh: ⁵log 1 = 0, ¹⁰log 1 = 0

2️⃣

Sifat 2: Logaritma Basis Sendiri

alog a = 1

alog a = 1

Karena a¹ = a, maka logaritma basis a dari a selalu 1.

Contoh: ³log 3 = 1, ⁷log 7 = 1

3️⃣

Sifat 3: Logaritma Perkalian

alog (b·c) = alog b + alog c

alog (b × c) = alog b + alog c

Logaritma dari perkalian sama dengan jumlah logaritma masing-masing bilangan.

Contoh: ²log 12 = ²log(4×3) = ²log 4 + ²log 3 = 2 + ²log 3

4️⃣

Sifat 4: Logaritma Pembagian

alog (b/c) = alog b − alog c

alog (b / c) = alog b − alog c

Logaritma dari pembagian sama dengan selisih logaritma pembilang dan penyebut.

Contoh: ²log(8/2) = ²log 8 − ²log 2 = 3 − 1 = 2

5️⃣

Sifat 5: Logaritma Perpangkatan

alog bn = n · alog b

alog bn = n × alog b

Pangkat pada numerus dapat dipindahkan menjadi koefisien di depan logaritma.

Contoh: ²log 8 = ²log 2³ = 3 × ²log 2 = 3 × 1 = 3

6️⃣

Sifat 6: Pangkat pada Basis

amlog bn = (n/m) · alog b

amlog bn = (n/m) × alog b

Pangkat pada basis dan numerus bisa dikeluarkan sebagai pecahan pengali.

Contoh: 4log 8 = 2²log 2³ = (3/2) × ²log 2 = 3/2

7️⃣

Sifat 7: Perubahan Basis

alog b = clog b / clog a

alog b = clog b / clog a

Logaritma dengan basis tertentu dapat diubah ke basis lain menggunakan rumus ini.

Contoh: ³log 5 = log 5 / log 3 (mengubah ke basis 10)

8️⃣

Sifat 8: Rantai Logaritma

alog b × blog c = alog c

alog b × blog c = alog c

Perkalian logaritma berantai: basis log kedua = numerus log pertama, hasilnya bisa disederhanakan.

Contoh: ²log 3 × ³log 8 = ²log 8 = 3

9️⃣

Sifat 9: Invers Logaritma

alog b = 1 / blog a

alog b = 1 / blog a

Logaritma dengan basis a dari b adalah kebalikan dari logaritma basis b dari a.

Contoh: ²log 5 = 1 / ⁵log 2

🔟

Sifat 10: Antilogaritma (Eksponen)

aalog b = b

aalog b = b

Jika basis dipangkatkan dengan logaritmanya, hasilnya adalah numerus itu sendiri.

Contoh: 2²log 8 = 2³ = 8
